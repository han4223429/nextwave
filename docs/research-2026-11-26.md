## 우리에게 해당하는 위험과 대응

| 지적된 패턴 | 출처 | 이 사이트에서의 대응 |
|---|---|---|
| 어두운 바탕에 빛나는 시안·네온 포인트 | A, C | 남색 바탕과 파랑은 로고에서 온 색이라 유지한다. 다만 glow, 네온 테두리, 빛번짐 그림자는 한 군데도 쓰지 않는다. 파랑은 3D 물결과 동작 요소에만 쓴다. 밝은 foam 구역을 섞어 어두운 화면만 이어지지 않게 한다. |
| 보라→파랑 그라데이션, 그라데이션 글자 | A, B, C, D | 쓰지 않는다. 색 전환은 3D 재질의 조명으로만 생긴다. |
| 글래스모피즘, 카드마다 같은 둥근 모서리와 그림자 | A, C, D | blur 패널과 그림자는 없다. 모서리는 버튼(pill), 화면(screen), 구역(없음) 세 단계로 나눈다. |
| 똑같은 3열 기능 카드, 아이콘 위 제목 | A, B, C | 카드 그리드를 쓰지 않는다. 목록, 타임라인, 실제 사진, 실제 데모를 쓴다. |
| 가운데 정렬 히어로(제목+부제+버튼 두 개) | A, B, C | 3D 물결이 화면을 차지하고, 글자는 왼쪽 아래 워드마크와 오른쪽 문단으로 나눈다. 주 버튼은 하나다. |
| 숫자 지표 줄("10,000+") | A, C | 쓰지 않는다. 대신 수상 6건을 날짜와 함께 사실대로 적는다. |
| 이모지 글머리, 스톡 이미지 | A, B, D | 쓰지 않는다. 운영진 실사진과 실제 프로젝트만 쓴다. |
| 모든 요소가 같은 fade-up, 바운스 이징, 계속 도는 펄스 | A, B, C | 자동 모션은 첫 화면의 물결이 일어나는 장면 하나뿐이다. 나머지는 사용자가 움직일 때만 반응한다. 이징은 물처럼 가라앉는 ease-out을 쓰고 튕기지 않는다. |
| hover·focus·disabled 상태 누락 | A | 모든 버튼과 링크에 세 상태를 넣는다. |
| 영어: 대시 남발, "seamless/empower/unlock", "Not just X but Y", 세 개씩 나열 | B, G | 영어 문구는 짧은 평서문으로 쓰고, 금지어 목록으로 검사한다. |
| 한국어: "~를 통해", "~에 있어서", "다양한/효과적/혁신적", "A가 아니라 B", 이중 피동, 문장 길이가 모두 같은 글 | E, F | "-아요/-어요" 구어체로 쓰고, 구체적인 장면(밤새, 캠퍼스, 학과명)을 넣는다. 금지어는 테스트로 검사한다. |

경고 [A]: 한 가지 기본값을 금지하면 그다음으로 흔한 모양(크림+테라코타, 검정+형광 초록)으로 옮겨 가기 쉽다. 그래서 결정은 동아리 고유의 것(로고, 1기, 실제 사람과 결과)에서 출발한다.

## 레퍼런스에서 가져온 원리 (베끼지 않음)
- **기수 아카이브와 "since"** (KUSITMS, YAPP, Depromeet) → "WAVE 01" 기록 구역. 2025년은 준비 기간, 2026년이 1기 출범이다.
- **사람 이름을 걸고 보여 주기** (YAPP의 운영진 카드, Hack Club의 만든 사람 표기) → 1기 창립 운영진 구역. 손글씨체로 쓴 이름과 실사진.
- **손맛** (Hack Club의 손글씨·스티커) → 템플릿 느낌을 줄이려고 펜글씨 이름과 실제 게임·3D 뷰어를 전면에 둔다.
- **모집이 닫혀 있을 때도 다음을 기다리게 하기** (Depromeet, Nexters의 "다음 기수 알림") → 서버가 없어 알림 신청 대신 "2기 탑승권" 만들기로 바꿨다. 지원서가 아니라는 점을 화면에 적는다.
- **결과물로 증명하기** (Depromeet, Nexters) → 프로젝트 구역에서 바로 해 볼 수 있는 데모를 유지한다.
- Next.js Conf 페이지에서는 개인 티켓을 확인하지 못했다. 티켓 아이디어는 이 페이지를 근거로 들지 않는다.
