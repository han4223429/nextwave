# NextWave 3D 물결 · 포트폴리오 체험 검토

기준: 2026-09-06, 로컬 `http://localhost:8000/?v=water-natural-2`. 사용자가 Chrome 검증과 Google 로그인 검증을 명시적으로 허용했습니다. 이전 사진 기반 물결 버전의 스크린샷을 이번 3D 메시의 검증 근거로 사용하지 않습니다.

## 포털과 Google 로그인

- 실제 Chrome에서 공개 기회 58건, 검색 결과 없음/초기화, 마케팅 7건 필터를 확인했습니다. 모바일에 가로 넘침이 없었습니다.
- ‘Google로 부원 로그인’을 두 번 시도했습니다. 두 번 모두 Google 인증 페이지까지 이동한 뒤 계정 선택 전에 Google의 `500. That’s an error.` 화면을 표시했습니다.
- 첫 오류 팝업을 닫으면 로그인 버튼이 다시 활성화되고 ‘로그인 창이 닫혔어요’ 안내가 나타났습니다. 공개 기회 목록은 유지되고 비공개 부원 영역은 숨겨져 있었습니다.
- 이후 `prompt: select_account` 적용으로 계정 선택 단계에 도달했지만 Google 동의 화면에서 401 오류가 관찰됐습니다. 상세 원인 진단을 계속하고 있습니다.
- 실제 로그인 성공, 신규 계정 승인 대기, 승인 부원·관리자 화면은 검증하지 못했습니다. 계정의 승인/관리자 권한을 변경하지 않았습니다. 이 화면만으로 Firebase 설정 문제인지 Google의 일시 오류인지 확정하지 않습니다. 자세한 경로와 복구 결과는 [로그인 QA](QA-AUTH-2026-09-06.md)에 기록했습니다.

## 3D 수면·RESCUE JET

- Chrome 1280×900과 390×844에서 실제 `data-renderer="webgl-3d"`, `data-surface="gerstner-ocean"`을 확인했습니다. 셰이더·콘솔 오류와 가로 넘침이 없었습니다.
- 고정된 말림과 사진을 제거한 넓은 수면입니다. 길이가 다른 다섯 파도가 전파되며 작은 햇빛 반사와 수면의 깊이감이 나타납니다. 모바일은 전체 폭, 약 200–250px 높이로 보이고 제목·버튼·인용 문구를 가리지 않습니다.
- RIPPLE / WAVE / DROPS 선택, 수면 파문, 드래그 시점 변화, MOTION 정지·재개, SOUND 상태 전환을 확인했습니다. 실제 음향 청취 품질을 검증한 것으로 표현하지 않습니다.
- RESCUE JET은 원본과 같은 주황색 U자 외형·추진 포드·재질·그림자·청록색 추진 입자를 확인했습니다. 회전 키보드 조작·확대·추진·분해·초기화·원본 이미지 복귀·재진입이 작동했습니다. 원본과 로컬의 화면 크기가 달라 픽셀 단위 일치를 주장하지 않습니다.
- 최종 로컬 수면 미리보기를 Chrome에서 deliverable로 표시했습니다.
