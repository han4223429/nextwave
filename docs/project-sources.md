# 실제 프로젝트와 웹 체험 근거

2026-09-06 공개 제작자 포트폴리오, 공식 게임 스토어, 제작자 GitHub를 확인했습니다. MAYHEM은 공개 점수식으로 이 사이트에서 새로 만든 웹 실험입니다. RESCUE JET은 사용자가 지정한 김한용 포트폴리오의 실제 3D 뷰어와 모델 코드를 이식한 체험입니다. RESCUE 모델은 공개 설계 이미지의 외형 재구성이며 실제 CAD나 하드웨어 제어가 아닙니다.

## MAYHEM — 메인 인터랙션으로 선택

- [제작자 이학주 포트폴리오](https://hakjulee.com/): 2025 SCHU AI·SW Festival 게임개발경진대회 최우수상, Unity 아케이드 액션, 물리 기반 이동과 멀티킬/스타일 점수의 결합을 직접 설명합니다. 구 포트폴리오 주소 `badwordfilter.github.io/portfolio/`는 이 도메인으로 연결됩니다.
- 공개 점수식: `킬 수 + Σ((멀티킬 수 - 1) × 스타일 점수)`.
- [HMBG 공식 프로젝트 소개](https://hmbg.kr/#projects)도 MAYHEM을 HMBG 대표작 및 수상작으로 소개합니다. 표기는 **“이학주 · HMBG 게임개발 동아리 프로젝트”**가 근거에 맞습니다. NextWave 단독 개발/소유로 표시하지 않습니다.
- 제작자가 제공한 [원작 시연 영상 1](https://youtu.be/Hd9ynbk7nds), [원작 시연 영상 2](https://youtu.be/Qo9u8bUePX8), [상장 PDF](https://hakjulee.com/Scan.pdf) 링크를 확인했습니다. 영상 플레이 자체와 PDF 내용은 이 조사에서 재생/열람 검증하지 않았습니다.
- 공식 설명에서 원작 키 매핑, 콤보 제한시간, 스타일 수치, 대시 지속시간은 확인되지 않았습니다. 공개 WebGL 원작 빌드도 찾지 못했습니다.
- [제작자의 SWAcademyFesitval 공개 저장소](https://github.com/BadWordFilter/SWAcademyFesitval)는 색상·프리즘·중력 퍼즐 관련 Unity 스크립트를 포함합니다. 이를 MAYHEM 원본 코드라고 입증할 근거는 없으므로 이 실험에 사용하지 않았습니다.

### 구현된 스타일 스코어 실험

`project-demo.js`의 Canvas 실험은 **“공개 규칙을 바탕으로 재구성한 웹 실험 · 원작 게임 아님”**으로 표시합니다. 원작의 로고·텍스처·레벨·소스코드·효과음을 복사하지 않았습니다.

- 30초 진행 시간. 화면 밖, 다른 탭, 창 비활성화 시 일시정지하며 사용자가 이어하기로 재개합니다.
- WASD/방향키 관성 이동, Space 대시, Enter 가장 가까운 표적 발사, 클릭/탭 직접 조준·발사. 키보드 게임 조작은 Canvas 포커스 안에서만 작동합니다. 네이티브 방향/대시/발사 버튼으로 같은 동작을 수행할 수 있습니다.
- 한 발에 동시에 맞은 표적을 하나의 멀티킬 묶음으로 계산합니다. 기본 스타일 1, 대시 직후 0.7초 스타일 3. 예: 한 발에 3개를 맞히면 기본 `3 + (3-1)×1 = 5점`, 대시 후 `3 + (3-1)×3 = 9점`입니다. 여러 발은 각 묶음의 보너스를 합산합니다.
- 발사 간격 0.35초, 대시 재사용 간격 1.4초, 사거리 350 Canvas 단위, 기본 범위 58/대시 범위 82는 **이번 체험의 자체 설계값**입니다. 원작 수치로 표현하지 않습니다.
- 모션 줄이기 설정 또는 사이트 수동 모션 정지(`html[data-motion="paused"]`)에서는 장식 회전을 멈추고 발사 궤적·확장 효과를 단순화합니다. 이동·조준·점수·라운드 시간은 필수 게임 조작으로 계속 작동합니다. 라이브 알림은 시작/정지/적중 같은 사건에만 사용하며 발사 알림은 빈도를 제한합니다.
- HTML 연결: `#mayhem-stage`, `#mayhem-canvas`, `#mayhem-start`, `#mayhem-reset`, `#mayhem-score`, `#mayhem-kills`, `#mayhem-combo`, `#mayhem-status`. 선택 사항 `#mayhem-time`. 버튼 `data-mayhem-action="up|down|left|right|dash|fire"`. `project-demo.js`를 defer script로 불러옵니다.
- 검증: `node --test tests/project-demo.test.cjs`. 점수식, 묶음별 합산, 중복 적중 방지, 일시정지/종료, 대시 창, 관성·경계, 시간 경과를 검증합니다.

## RESCUE JET — 공개 포트폴리오의 동일한 3D 체험

사용자가 [김한용 포트폴리오](https://han4223429.github.io/portfolio/)의 체험과 동일하게 구현하도록 지정했습니다. 공개 페이지와 다음 파일을 HTTP로 읽어 모두 200 응답을 확인했고, 인접 소유자 체크아웃과 SHA-256이 일치하는 것을 확인했습니다. 인접 프로젝트는 읽기만 했습니다.

- [원본 뷰어](https://han4223429.github.io/portfolio/rescue-viewer.js): 지연 로딩, 카메라·조명, 조작, 추진 표현, 분해 보기, 수명주기.
- [원본 모델](https://han4223429.github.io/portfolio/rescue-model.js): 주황색 U자 외형, 반사띠·흰 화살표, 원통형 추진부, 단순화된 프로펠러와 가드. `assets/rescue/rescue-model.js`는 원본과 바이트가 같습니다.
- [원본 스타일](https://han4223429.github.io/portfolio/rescue-viewer.css): 중립색 배경, 원본 이미지와 실행 버튼, 모델 상단 헤더, 하단 조작·안내 구성.
- `assets/rescue-jet.jpg`는 동일한 819×631 원본 설계 이미지입니다. 실물 촬영 사진으로 설명하지 않습니다.

### 이식한 동작과 범위

`rescue-demo.js` / `rescue-demo.css`는 공개 뷰어를 NextWave의 `#rescue-project-panel`에 연결합니다. 원본 모델·색·카메라·조명·추진·분해 수치는 유지했습니다. 기존의 별도 화살표 개념도와 화면 강도 슬라이더는 이 뷰어로 교체했습니다.

- **3D로 살펴보기**를 누를 때 로컬 Three.js와 모델을 처음 불러옵니다. 처음부터 엔진을 다운로드하거나 원격 실행 스크립트를 요청하지 않습니다.
- 드래그·방향키 회전, `+` / `-` 확대·축소, `R` 초기화. 네이티브 확대/축소/초기화 버튼도 제공합니다. 터치의 세로 페이지 스크롤은 유지합니다.
- **추진 데모**는 프로펠러와 두 추진부의 방향 입자를 표현하고 **분해 보기**는 상부 외형과 추진부를 분리합니다. 원본 체험처럼 조립 보기와 초기 상태로 돌아갈 수 있습니다.
- **원본 이미지**는 뷰어를 닫고 설계 이미지를 다시 보여줍니다. WebGL/모듈 실패 시에도 이미지와 재시도 버튼을 유지합니다.
- NextWave 탭의 숨김 상태, 한/영 문구·접근성 라벨, 전역 수동 모션 정지를 연결했습니다. 시스템 또는 수동 모션 정지 상태에서는 정지된 추진 방향과 즉시 바뀌는 분해 상태를 보여줍니다. 화면 밖·다른 탭에서는 렌더링을 멈춥니다.
- 제작자는 **멤버 김한용**입니다. 프로젝트는 2025 SCOUT 제품제작역량 캠프/창업대회 자동구명추진장치로 소개하며, 하드웨어 설계·제작, Arduino 제어, 3D 프린팅 하우징은 제작자 설명에 근거합니다. 이 웹 외형을 원본 CAD·치수·성능·유체 해석 결과로 제시하지 않습니다.

Three.js **r180** 모듈과 상대 경로 core 모듈은 원본에 포함된 파일을 `assets/vendor/three/`에 복사했습니다. 두 파일의 합계는 720,032바이트이며 MIT 라이선스를 같은 폴더의 `LICENSE`에 보존합니다. 원본 실행 아이콘과 라이선스는 `assets/rescue/`에 있습니다.

정적 검사는 로컬 모듈·자산·라이선스 경로, DOM ID와 탭 연결, 한/영 문구·ARIA 쌍을 확인했습니다. `node --test tests/rescue-model.test.mjs`는 실제 복사 모델과 Three.js를 CPU에서 사용해 유한한 외형, 두 추진 방향, 분해 상태의 가역성·입력 경계, 자원 해제를 검사합니다. WebGL을 초기화하지 않는 검사이며 브라우저 결과는 [현재 QA 기록](QA-WATER-2026-09-06.md)에서 구분합니다.

### 구현하지 않은 후보

**올담 데이터 활용 해커톤**은 2025년 7~8월 공공데이터 탐색·분석, 실생활 문제 정의, 서비스 기획·발표와 최우수상을 제작자 포트폴리오에서 확인했습니다. 서비스명, 구체적 데이터셋, 실행 앱이나 소스 링크가 공개 설명에 없어 임의의 앱을 수상작 데모로 만들지 않았습니다. 김한용의 참여 기록으로만 소개합니다.
