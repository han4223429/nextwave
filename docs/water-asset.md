# NextWave 실시간 3D 수면

2026-09-06 사용자가 사진 대신 직접 움직일 수 있는 3D 물결을 요청했습니다. 메인에서 생성 PNG·이미지 preload·사진 굴절 텍스처를 제거했습니다. 이전 생성 자산은 현재 사이트에 포함하지 않습니다.

## 구현

- `kinetic.js`: 25,920개 삼각형, 원근 카메라, 다섯 Gerstner 파도의 수면 높이·법선, 작은 햇빛 반사와 프레넬 효과를 WebGL로 렌더링합니다. 고정된 말림은 제거했습니다.
- `index.html`: `#kinetic-stage` / `#kinetic-canvas`와 RIPPLE / WAVE / DROPS·물결 만들기·MOTION 버튼을 연결합니다.
- `styles.css`: 데스크톱의 제목 여백과 모바일의 독립적인 수면 영역을 구성합니다.
- 클릭/터치의 파문과 드래그 시점 조작을 제공합니다. 소리는 기본 OFF이며 사용자가 켠 상태의 직접 조작에만 반응합니다.
- 화면 밖·숨겨진 탭·모션 줄이기·수동 정지와 WebGL 실패 상태를 처리합니다.

이는 브랜드를 직접 만져보는 수면 시각화이며 실제 유체 해석이나 정량적인 해양 시뮬레이터가 아닙니다. 모델 메시와 수면 함수는 코드로 생성하며 배경 사진·이미지 텍스처·외부 3D 서비스가 필요하지 않습니다.

현재 버전의 실제 화면·GPU·모바일·조작 확인 결과는 [QA 기록](QA-WATER-2026-09-06.md)에 정리합니다.
