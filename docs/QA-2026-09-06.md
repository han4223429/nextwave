## 추가 검수에서 발견하여 수정한 항목

- 자동 갱신 시 출처 링크 및 갱신 후에도 남아 있는 공고 링크의 키보드 포커스를 보존합니다. 회귀 테스트를 추가했고, 실제 포털에서 K-Startup 링크에 포커스를 둔 뒤 1분 주기 재조회 후에도 유지됨을 확인했습니다. 서버 로그의 21:49:47 수집본 재조회와 브라우저21:50:29의 포커스 상태를 대조했습니다.
- 실제 공고5건의 분류를 보정했습니다. 봉사활동·교류/네트워킹은 대외활동, AI 광고·영상 제작 공모전은 마케팅으로 분류합니다. 기관명에 포함된 ‘연구개발’만으로 개발로 판단하지 않습니다. `classificationVersion: 2`이며 원문 확인 시각·마감일·ID는 변경하지 않았습니다.
- 실제 모바일 포털에서 ‘남이섬’ 검색 결과가 마케팅으로 표시되고, 검색어를 지우면 마케팅7건으로 복귀하는 것을 확인했습니다.
- FAQ 키보드 열기/닫기, 활동 아코디언의 한 항목씩 펼치기를 실제 브라우저에서 확인했습니다.
- 더 보기12→24→36→48→58 흐름과 마지막10개 표시 후 버튼 종료, 새 공고로 포커스 이동을 확인했습니다. 모바일390px에서58개 전체를 펼쳐도 공고 영역 가로 넘침이 없었습니다.

현재 자동 검사 합계는 **41개**(크롤러25, 포털10, Firestore 규칙6)입니다. 변경하지 않은 Firestore 규칙 테스트는 기존 실제 에뮬레이터 통과 결과를 사용합니다.
